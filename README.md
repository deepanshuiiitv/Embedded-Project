# Fabrication, Characterization, and Intelligent Analytics of Capacitive Leaf Wetness Sensor

## Abstract

This project focuses on the design, development, characterization, and intelligent analysis of a flexible capacitive leaf wetness sensor for smart agriculture. The sensor uses interdigitated electrodes fabricated on a polyimide substrate and an ESP8266-based embedded system for data acquisition. Machine learning models, including Linear Regression, Random Forest, and XGBoost, were developed to predict leaf wetness levels from sensor data. Random Forest achieved the best performance with high prediction accuracy, demonstrating the potential of combining embedded sensing with AI for precision farming.

## Objectives

* Design and fabricate a lightweight flexible capacitive leaf wetness sensor.
* Analyze sensor behavior under different moisture conditions.
* Develop an ESP8266-based embedded data acquisition system.
* Characterize frequency response and wetness sensitivity.
* Apply machine learning techniques for leaf wetness prediction.
* Enable intelligent sensing solutions for smart agriculture.

## Methodology

* Designed interdigitated electrode structures using Eagle software.
* Fabricated a flexible capacitive leaf wetness sensor on a polyimide substrate.
* Developed signal conditioning and capacitance-to-frequency conversion circuitry.
* Integrated the sensor with an ESP8266-based data acquisition system.
* Conducted characterization experiments under varying wetness conditions.
* Collected and processed frequency response data.
* Applied feature engineering and data augmentation techniques.
* Built and evaluated Linear Regression, Random Forest, and XGBoost models.
* Assessed model performance using RMSE, MAE, and R² metrics.

## Results

* Successfully fabricated and characterized a flexible leaf wetness sensor.
* Demonstrated measurable frequency variation across different wetness levels.
* Developed an ESP8266-based embedded data acquisition system.
* Built machine learning models for accurate leaf wetness prediction.
* Achieved the best performance with Random Forest:

  * **RMSE:** 3.09
  * **MAE:** 1.98
  * **R² Score:** 0.989
* Validated the effectiveness of integrating intelligent analytics with sensor technology for precision agriculture.
